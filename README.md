# Blockaidia feed

Data the Blockaidia launcher reads while it runs:

- `feed.json`: the sidebar promos, the Community page and the server directory.
- `update-beta.json` (once betas ship): the beta update channel.

These files are edited in the main Blockaidia project under `feed/` and published here with
`Publish feed.bat`. The next publish overwrites anything changed directly in this repository.
